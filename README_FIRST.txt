GENESIS 2.2 - HOW TO RUN
========================

Extract this zip into your Documents folder (replace files when asked).
Your settings (.env), Gemini key and installed packages are kept.

1. UPDATE: double-click  Update_Genesis.bat  (once).
2. COLAB: say 'open google colab' - a Chrome window opens; sign in to your Google account there ONCE.
3. FREE IMAGE GENERATION (optional): Setup_Images.bat
4. Only if needed: Fix_Genesis.bat (AI model), Fix_Voice.bat ('Hey Genesis' doesn't react).

Try: in an online compiler, click in the editor, then: 'write a program for bubble sort and run it'
     'which window am I in?'   'what did you hear?'
     'write a python program for fibonacci in colab and run it'   'edit the cell to print the first 20 numbers'

If Windows says 'Windows protected your PC': click More info > Run anyway.
